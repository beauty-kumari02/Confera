# Confera – Video Conferencing Platform  

Confera is a full-stack video conferencing web application that allows users to connect, collaborate, and communicate in real-time.  
It provides features like sign-up/sign-in authentication, real-time screen sharing, chat, and mic/video toggle options — making online meetings seamless and interactive.  

--------------------------------------------------------------------------------------------------------------------------------------------------------------------------

## Features  
- *User Authentication:* Secure sign-up and login system  
- *Real-Time Communication:* Low-latency audio and video calls using WebRTC  
- *Screen Sharing:* Share entire screen or specific application window  
- *Live Chat:* Built-in real-time chat for smooth collaboration  
- *Media Controls:* Mic and video toggle options  
- *Responsive UI:* Works on desktop and mobile browsers  

---------------------------------------------------------------------------------------------------------------------------------------------------------------------------

## Tech Stack  
- *Frontend:* React.js  
- *Backend:* Node.js  
- *Real-time Communication:* Socket.io, WebRTC
